WHAT'S NEW IN THIS BUILD

• Queued pads that never fired are fixed: pads armed to a bar boundary
  (hourglass badge) could stay armed forever on a fresh app launch.
  They now always fire on their boundary.
• Learn tab fretboard is never empty: before the first chord (and in
  chord gaps) it now shows the upcoming chord primed, like web — no
  more bare neck with floating dashed rings.
• Chord charts show finger numbers inside the dots and a barre capsule,
  matching the web diagrams.
• Transition coaching: a countdown bar + a text hint ("Same shape
  +2 frets", "Move one finger only", "Barre at fret 1") now sits under
  the Learn fretboard.
• Everything from the previous build: full pad-timing parity with web,
  playable section/chord pads on the 64 grid, tap-to-add in Add Sound,
  cleaner Build tab.

HOW TO USE THE NEW FEATURES

Learn coaching:
1. Library → open an analyzed song → Learn tab.
2. Before pressing play: the fretboard shows the song's first chord.
3. Press play: the NEXT pill, countdown bar and hint update as chords
   approach; dashed rings show where fingers land next.

Queued pads:
1. Build tab → Samples → Latch.
2. Tap several loop pads in a row, any time. Each shows an hourglass
   until the next bar, then fires.

WHAT TO TEST

1. FRESH LAUNCH, then immediately: Latch + tap 3-4 loop pads quickly.
   Expected = every armed (hourglass) pad starts on the next bar and
   stays in sync. Report any pad stuck on the hourglass or silent.
2. Learn tab before pressing play: expected = first chord drawn solid,
   with finger numbers; no empty fretboard, no stray dashed circles.
3. Play through a song with chord changes: countdown + hint text should
   track the next chord; barre chords (F, Bm) show the barre capsule.
4. Repeat test 1 mid-session (after pads have played once): expected =
   identical behavior.

KNOWN LIMITATIONS
• 64-pad grid size is remembered per device — fresh installs default
  to 16; tap 64 once.

WHAT TO REPORT
• Any hourglass pad that never fires (say: fresh launch or mid-session,
  song playing or stopped, which pads).
• Any empty Learn fretboard (say what the song/position was).
