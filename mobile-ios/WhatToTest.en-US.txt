WHAT'S NEW IN THIS BUILD

• Edit mode no longer sounds the pad. Holding a pad to open the radial
  menu used to fire it on/off (an audible blip) — in Edit mode a pad
  touch is now silent; only the hold-for-radial gesture acts. Toggle
  Edit off to play.
• (Also in the last build, in case you missed it) Tap | Loop | Latch
  trigger modes: Tap = zero-latency gate (instant, hold to sustain,
  release stops); Loop = beat-locked hold-to-play; Latch = tap on/off.
  Section/chord pads on the 64 grid show their loop indicator + a type
  label ("Vocals / Intro", "Chord / D"). Perform stages the grid size
  you set in Build.

HOW TO USE EDIT MODE

1. Build → Samples. Tap the pencil "Edit" chip (right end of the chip
   row).
2. Edit ON: hold a pad → the radial editing wheel opens, NO sound.
3. Edit OFF: pads play normally (Tap/Loop/Latch as chosen).

WHAT TO TEST

1. Edit ON: hold several pads to open the radial — expected = NO audio
   blip, just the wheel. Pick Loop/Chop/etc.
2. Edit OFF + Tap: hit a pad — instant sound, hold sustains, release
   stops.
3. Green/purple 64-grid pads in Latch — loop badge + glow show, labels
   read "Vocals/Intro" or "Chord/D".
4. Build 64 → Perform — full 8×8 on stage.

WHAT TO REPORT
• Any sound when touching a pad with Edit ON.
• Any Tap pad that keeps playing after you lift.
