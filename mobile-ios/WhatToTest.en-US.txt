Jamn — TestFlight build notes

WHAT'S NEW THIS BUILD
Three Launchpad regressions fixed on the Samples pad grid:
• HOLD MENU IS BACK. Long-pressing a pad again opens the radial wheel
  (Add Sound / Chop / Loop / Effects / Sequence / Delete on a filled pad;
  Add Sound / Voice / Beat Capture / Sequence on an empty one). It had gone
  missing on the 64-pad grid — the big grid now uses the same rich pads as
  the 16-pad grid, so hold-to-edit works at either size.
• WAVEFORMS ARE BACK. Each sample pad again draws its little audio waveform
  (the actual sound that plays, trimmed). Previously the 64-pad grid showed
  flat colored squares with no waveform.
• BORROWED PADS NOW NAME THEIR SONG. A borrowed pad shows the SOURCE-SONG
  name (your song vs the borrowed song) as a small line above the pad's
  chord/section label — so you can tell which pad came from which song, not
  just guess from the blue/amber color. This was missing on the 16-pad
  best-of-both borrow view.

HOW TO USE
• HOLD MENU: Learn or Perform → Samples pads. Press and HOLD a pad (~0.5 s)
  until the wheel appears, then slide toward an action and release. Works on
  both the 16 and 64 pad sizes (the "Pads 16 | 64" toggle above the grid).
• WAVEFORMS: just open the Samples pads with a song loaded — filled pads draw
  their waveform automatically. Toggle to 64 to confirm the big grid shows
  them too.
• BORROW SONG LABELS: Song → Remix → Borrow (or the "Add Song" chip) → pick
  Beat/Bass/Chords/Melody → a suggested song. Pads fill blue (your song) /
  amber (borrowed song). Each borrowed pad now shows the song name in small
  text above the chord/section name. Try both the 16 and 64 sizes.

WHAT TO TEST
1. HOLD MENU @ 64: Set the size toggle to 64. Long-press a filled pad — the
   radial wheel should open (NOT a full-screen sheet). Pick "Loop" or "Chop"
   and confirm it acts on that pad. Repeat at 16.
2. HOLD MENU on empty pad: Long-press an empty "+" cell — the create wheel
   (Add Sound / Voice / Beat Capture / Sequence) should open.
3. WAVEFORMS @ 64: Toggle to 64. Filled pads should each show a small
   waveform, not a plain colored square. Tap a pad; the waveform is the audio
   that plays.
4. BORROW SONG LABEL @ 16: Borrow a song, set size to 16 (best-of-both).
   Every pad should show its source-song name above the chord/section label;
   your song's pads blue, the borrowed song's pads amber.
5. BORROW SONG LABEL @ 64: Same borrow, toggle to 64 — song labels still
   present across the full grid, tints intact.
6. NO REGRESSIONS: Contribute/Build 8×8 arrange grid still swaps pads by
   drag; Perform stage pads still play; adding a sound to an empty pad still
   works.

KNOWN LIMITATIONS
• On the 64 grid the pads are small, so names are one line and the waveform
  is shorter than on the 16 grid — by design, to keep 64 pads legible.
• A non-borrow kit at 64 shows its 16 kit pads plus empty "+" cells (same as
  before) — 64 is most useful with a borrow loaded.
• First Borrow per (song, donor) renders on the server then caches — first
  tap is slower.
