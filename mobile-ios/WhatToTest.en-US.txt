WHAT'S NEW IN THIS BUILD

• Sample trigger modes are now One-Shot | Follow | Latch (replaces
  Tap | Loop | Latch):
  – One-Shot = finger-drumming. Every tap plays the sample FROM THE
    BEGINNING, no clock sync. Hold to sustain, release stops. Tap fast
    to retrigger from the top each time.
  – Follow = plays IN SYNC with the other pads (locks to the shared
    clock point). This is the old "Tap" you liked — renamed. Release
    stops.
  – Latch = synced loop, tap on / tap off (unchanged).
• Loop mode is gone (it overlapped with Latch). If you were on Tap or
  Loop, you're now on Follow.

HOW TO USE

Build → Samples. The mode chips (One-Shot | Follow | Latch) lead the
row above the pads.
• One-Shot: tap a pad — it plays from the sample start every time. Great
  for drum hits / finger-drumming.
• Follow: tap pads — they lock to the same clock position so layers stay
  in time.
• Latch: tap to start a loop, tap again to stop.

WHAT TO TEST

1. One-Shot: tap a pad repeatedly — expected = restarts from the TOP
   each tap, instant, no sync. Hold = sustains, release = stops.
2. Follow: with a few pads going, tap another — expected = it drops in
   IN SYNC at the shared clock point (not from the top).
3. Latch: tap on / tap off a synced loop.
4. Plug in a Launchpad (if you have one): One-Shot gives instant
   from-the-top hits on the hardware too.

WHAT TO REPORT
• Any One-Shot pad that does NOT start from the beginning.
• Any Follow pad that starts from the top instead of locking to the mix.
